## 0.18.7 - 2026-10-06
### Added
* backend: expose backend.taskManager.resources to set CPU/memory/ephemeral-storage requests and limits on the task-manager (worker) container independently. When left empty it falls back to backend.resources, so existing deployments are unchanged. ([Pull #323](https://github.com/cycloidio/ansible-cycloid-onprem/issues/323))
### Security
* backend/frontend: the backend pods (API, migrations initContainer, task-manager) and the frontend pod no longer mount their ServiceAccount token by default (automountServiceAccountToken=false), reducing the attack surface. They do not call the Kubernetes API. Set backend.automountServiceAccountToken / backend.taskManager.automountServiceAccountToken / frontend.automountServiceAccountToken to true if you bind the ServiceAccount to RBAC. ([Pull #323](https://github.com/cycloidio/ansible-cycloid-onprem/issues/323))
