## 0.17.0 - 2026-05-22
### Added
* support plugins k8s runtime ([Pull #288](https://github.com/cycloidio/ansible-cycloid-onprem/issues/288))
* scripts/update-vault-creds.sh: re-runnable helper to refresh Vault approle credentials in values.custom.yaml after the initial init (when vault-config.sh's placeholder-based sed no longer applies). ([Pull #290](https://github.com/cycloidio/ansible-cycloid-onprem/issues/290))
### Changed
* concourse/postgres: relocate data into a pgdata/ subdirectory (PGDATA) to avoid AWS EBS / ext4 'lost+found' blocking initdb on fresh volumes. Existing deployments are migrated automatically on first start. ([Pull #290](https://github.com/cycloidio/ansible-cycloid-onprem/issues/290))
### Removed
* concourse/postgres, mysql: drop the Bitnami-to-official-image migration commandOverride (postgres) and the equivalent on the mysql subchart (bumped to 0.1.7). The migration was a one-shot already applied to every existing deployment by chart 0.16.x. ([Pull #290](https://github.com/cycloidio/ansible-cycloid-onprem/issues/290))
