## 0.18.6 - 2026-09-07
### Removed
* concourse/postgres: drop the one-shot pgdata/ layout migration commandOverride. The migration was applied to every existing deployment on first start with chart 0.17.x; PGDATA in extraEnvironment is enough on its own now. ([Pull #0](https://github.com/cycloidio/ansible-cycloid-onprem/issues/0))
### Fixed
* plugins: switching plugins.deploymentRuntime from k8s to cri no longer leaves the plugin-manager Deployment referencing the deleted ServiceAccount. serviceAccountName is now always rendered ("default" under cri), so the stale reference is overwritten instead of hanging the helm upgrade with a ReplicaFailure. ([Pull #316](https://github.com/cycloidio/ansible-cycloid-onprem/issues/316))
* plugins: grant the Plugin Manager permission on HorizontalPodAutoscalers ([Pull #315](https://github.com/cycloidio/ansible-cycloid-onprem/issues/315))
