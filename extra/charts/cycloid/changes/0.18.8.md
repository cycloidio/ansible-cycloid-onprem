## 0.18.8 - 2026-10-22
### Added
* plugins: expose plugins.podSecurityContext and plugins.securityContext to set a pod-level and container-level security context on the Plugin Manager and Plugin Registry pods, consistent with backend/frontend. The container securityContext is only applied when plugins.deploymentRuntime="k8s"; under "cri" the plugin containers keep privileged=true as required to reach the containerd socket. ([Pull #325](https://github.com/cycloidio/ansible-cycloid-onprem/issues/325))
* externalRedis: add externalRedis.sentinel (masterSet and a nodes list of {host, port}) to connect Cycloid to a Redis Sentinel (high availability) cluster. Sentinel mode is enabled by providing sentinel.nodes; REDIS_URI is then generated with the "redis-sentinel://" scheme for all workloads (backend, plugins-manager, plugins-registry and cronjobs), so a single definition covers every component. Node port defaults to 26379 when omitted. TLS keeps working as before by injecting REDIS_CA_CERT via backend.extraSecretEnvVars. ([Pull #1](https://github.com/cycloidio/ansible-cycloid-onprem/issues/1))
